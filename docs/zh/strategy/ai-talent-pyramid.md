# 乔治AI人才金字塔

> George AI Talent Pyramid - 战略层方法论

## 📊 模型概述

AI人才金字塔是一个四层架构模型，用于指导企业构建完整的AI人才体系。

```
          ┌─────────────────┐
          │   AI战略委员会   │  ← 董事会层 (3-5人)
          │  (年薪: 500万+)  │
          ├─────────────────┤
          │    CAIO/CDO     │  ← C层级 (1人)
          │  (年薪: 200-500万)│
          ├─────────────────┤
          │  AI产品/技术VP   │  ← VP层级 (2-5人)
          │  (年薪: 80-200万)│
          ├─────────────────┤
          │  AI工程师/专家   │  ← 执行层 (10-100人)
          │  (年薪: 30-80万) │
          └─────────────────┘
```

## 🎯 每层详解

### 第一层：AI战略委员会 (董事会层)

**职责：**
- AI战略方向决策
- 重大AI投资审批
- AI伦理与合规监督

**人员构成：**
- CEO/董事长 (主席)
- CTO/技术VP
- 外部AI顾问 (1-2人)
- 独立董事代表

**会议频率：** 每季度1次

---

### 第二层：CAIO/CDO (C层级)

**全称：** Chief AI Officer / Chief Data Officer

**核心职责：**
1. 制定企业AI战略路线图
2. 统筹AI项目资源分配
3. 建立AI治理框架
4. 向董事会汇报AI进展

**胜任力要求：**
- 技术背景 + 商业敏锐度
- 跨部门协调能力
- 高管沟通与影响力

---

### 第三层：AI产品/技术VP (VP层级)

**岗位类型：**
- AI产品VP
- AI技术VP/CTO
- 数据科学VP
- AI工程VP

**团队规模：** 10-50人

---

### 第四层：AI工程师/专家 (执行层)

**岗位分类：**
| 类别 | 岗位示例 | 技能要求 |
|------|----------|----------|
| 算法类 | 机器学习工程师 | Python, TensorFlow, PyTorch |
| 工程类 | MLOps工程师 | K8s, Docker, CI/CD |
| 数据类 | 数据工程师 | SQL, Spark, ETL |
| 产品类 | AI产品经理 | 需求分析, 原型设计 |

---

## 💡 应用建议

### 创业企业 (10-50人)
- 建议配置：CAIO + 3-5名AI工程师
- 优先考虑：全栈AI工程师

### 成长企业 (50-200人)
- 建议配置：CAIO + AI技术VP + 10-20名AI团队
- 建立专门的AI部门

### 大型企业 (2000+人)
- 建议配置：完整金字塔架构
- 设立AI战略委员会
- 建立AI Center of Excellence
