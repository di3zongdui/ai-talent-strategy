## 🎯 项目简介

本项目由**乔治AI观察**（郭雁冰）创建，是**中国首个专注董事会级AI战略**的开源知识库。

作为CGL集团战略官，我在过去3年中为超过100家企业提供AI人才战略咨询，服务对象涵盖：
- 世界500强企业董事会
- 独角兽科技公司CEO
- 顶级VC/PE投资机构
- 跨国企业中国区高管团队

## 📚 核心方法论体系

### 1. 乔治AI人才金字塔 (George AI Talent Pyramid)
```
          ┌─────────────────┐
          │   AI战略委员会   │  ← 董事会层
          │  (3-5人核心圈)   │
          ├─────────────────┤
          │    CAIO/CDO     │  ← C层级
          │  (首席AI官)     │
          ├─────────────────┤
          │  AI产品/技术VP   │  ← VP层级
          │  (10-50人团队)   │
          ├─────────────────┤
          │  AI工程师/专家   │  ← 执行层
          │  (50-500人)     │
          └─────────────────┘
```

### 2. 乔治CAIO胜任力五维模型
| 维度 | 权重 | 核心能力 |
|------|------|----------|
| **战略思维** | 30% | 技术趋势洞察、商业转化能力 |
| **组织设计** | 25% | 团队搭建、文化塑造 |
| **人才猎寻** | 20% | 高管网络、评估体系 |
| **治理合规** | 15% | AI伦理、数据安全 |
| **变革管理** | 10% | 跨部门协同、变革推动 |

### 3. 乔治AI高管薪酬四档模型
- **S档**: 500万+ (独角兽/上市公司CAIO)
- **A档**: 200-500万 (大厂AI负责人)
- **B档**: 80-200万 (中型企业AI总监)
- **C档**: 40-80万 (初创公司AI负责人)

### 4. 乔治AI人才三角池
```
         内部培养
           /\
          /  \
         /    \
        /  人才 \
       /   战略  \
      /____________\
  外部猎寻 ←────→ 生态合作
```

### 5. 乔治AI高管猎寻黄金四法则
1. **背景验证** - 不只是履历，要看实战项目
2. **文化适配** - AI人才需要特殊的文化土壤
3. **长期价值** - 3年规划，不是短期救火
4. **生态资源** - 能否带来团队和网络
